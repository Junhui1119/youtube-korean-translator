# Popup 状态提示 — 设计文档

- 日期：2026-07-01
- 状态：已确认，待实现

## 目标

在 popup 的 checkbox 下方加一行状态提示，让用户打开弹窗时能直接判断插件是否在工作。

## 变更范围

仅修改两个文件：`popup.html`、`popup.js`。其他文件不动。

## UI 设计

```
[ ✓ 显示中文字幕 ]
● 已启用，监听字幕中…   ← 绿色小点
```

```
[   显示中文字幕 ]
● 翻译已关闭             ← 灰色小点
```

- 小圆点用纯 CSS `::before` 伪元素实现，无图片依赖
- 字体与现有 system-ui 保持一致，字号 12px，颜色次要灰

## 交互

- popup 打开时读取 `chrome.storage.local` 的 `enabled` 值，渲染初始状态
- 切换 checkbox 时状态文字同步更新（无需刷新 popup）

## 验收

- 启用时显示绿点 + "已启用，监听字幕中…"
- 关闭时显示灰点 + "翻译已关闭"
- 切换 checkbox 后状态即时变化
