# 游戏 / 直播术语库（韩语 → 中文）

这个目录存放**术语校正库**：在机器翻译之后，用它把游戏术语、直播梗、人名等机翻常错的词替换成更地道的中文。

这是在**不更换翻译引擎**的前提下提升翻译质量的主要手段，直接对应 PRD 里「术语翻不准」的质量门槛问题。

## 文件

- `ko-zh-game-terms.csv` —— 术语词条表。**你之后往这里补充词条即可。**

## 词条格式

CSV，四列：

| 列 | 含义 | 是否必填 |
|----|------|----------|
| `korean` | 韩语原词 | 必填 |
| `chinese` | 期望的中文译法 | 必填 |
| `category` | 分类（如 LOL / FPS / 主播梗 / 人名 / 直播用语） | 可选 |
| `note` | 备注 | 可选 |

规则：
- 一行一个词条；以 `#` 开头的行是注释，会被忽略。
- 含逗号的内容用英文双引号包起来，例如 `"한타,교전"`。
- 同一韩语词在不同游戏里含义不同时，可以写多条，用 `category` 区分。

## 之后怎么用（设计预期，v1 实现时再定细节）

1. 插件加载时读入术语库，建立「韩语词 → 中文」映射。
2. 机器翻译产出中文后，对照原韩语字幕，命中术语库的词用库里的译法覆盖。
3. 术语库更新无需改代码，编辑 CSV 即可。

> 注：以上为预期用法，最终在 v1 实现阶段确定（是按韩语原词匹配，还是对中文译文做替换）。
